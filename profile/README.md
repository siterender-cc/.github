# SiteRender

What a page sends, what a browser builds, and which one you actually need.

- **Website:** [siterender.cc](https://siterender.cc)
- **Blog:** [siterender.cc/blog](https://siterender.cc/blog) · **Guides:** [siterender.cc/guides](https://siterender.cc/guides)
- **Docs:** [siterender.cc/docs](https://siterender.cc/docs)
- **CLI:** [`siterender`](https://github.com/siterender-cc/cli), live web pages as Markdown from your terminal ([docs](https://siterender.cc/docs/cli), [npm](https://www.npmjs.com/package/@siterender-cc/cli))

```bash
npx @siterender-cc/cli fetch https://example.com -o text
```

A [Teneo Labs](https://siterender.cc/imprint) project, built on the [Live Web Data API](https://livewebdata.com).
